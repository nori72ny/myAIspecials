# V1.4 Coding Readiness UI

The Coding workspace renders only non-secret readiness metadata already returned by `/api/coding/v1.4/status`.

It shows controller/control-plane readiness, database/store configuration, live schema reachability, owner binding, encryption readiness, dedicated Coding authorization, GitHub dispatch readiness, and the worker opt-in flag.

The UI does not render environment values, database URIs, bearer credentials, GitHub tokens, encryption keys, owner HMAC material, or secret-derived diagnostics. Missing prerequisites keep new submissions fail-closed. Existing owner-scoped job lookup/cancellation remains governed by the narrower human-control boundary already implemented in V1.4.

This visibility improvement does not add Git publication, deployment authority, paid fallback, or Claude Code parity claims.
