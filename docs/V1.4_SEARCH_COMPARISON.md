# Reproducible V1.4 search comparison

Run from a full repository checkout:

```sh
node --import tsx scripts/compare-coding-search-v14.ts
```

The script extracts the historical search implementation at
`2b905df35747632bb408ff90b50e54cc9e6d87b3`, compiles it against the same safe IO
helpers as the current implementation, and runs both on identical temporary
repositories. All temporary files are removed. No provider or network is used.
The scoring rule requires the expected path, line and literal to be visible in
returned evidence. These are synthetic development regressions, not held-out
tasks, model-generation scores or an end-to-end coding benchmark.

This update corrects offset drift caused by lowercasing Unicode text before
locating excerpts. Escaped literal matching now returns offsets in the original
source. Eight metacharacter regression cases verify that user input is never
interpreted as a regex expression. The existing file, byte and output limits stay
in place. The 17 Coding suites pass 137 tests locally after this update.

No superiority over Claude Code, ChatGPT or another AI has been measured. The
development environment has no configured OpenRouter key, and no competing
model credentials or outputs are available for a matched comparison. This
report cannot establish general answer quality, latency, hidden-task success,
production reliability or overall model ranking. Current free-only/no-fallback
policy remains unchanged.
