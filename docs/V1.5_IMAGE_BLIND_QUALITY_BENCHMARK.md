# V1.5 Image Blind Quality Benchmark

Status: evaluation protocol. This does not claim that ORIGIN image generation already exceeds other systems.

## Purpose

This benchmark measures image-output quality, not whether an endpoint merely returned bytes.

A Release 2 raster path can be operational before this benchmark passes, but it must not be described as quality-complete or superior to leading image systems until the exact candidate passes this benchmark.

## Frozen shape

The official round contains exactly 24 cases:

- photograph: 3
- portrait: 3
- product: 3
- advertisement: 3
- social: 3
- poster: 3
- thumbnail: 3
- illustration: 3

The actual prompt text should be frozen outside participant-visible source before the evaluation round. Public evidence records only case ID and prompt SHA-256.

Do not tune ORIGIN against the sealed prompts after seeing benchmark results.

## Deterministic pre-qualification

Before any subjective judging, every ORIGIN image must pass:

- MIME/signature validation
- exact requested dimensions
- structural critic
- technical pixel critic
- safety checks
- delivery-integrity check

A technically invalid image is a failed benchmark case even if a judge prefers its appearance.

## Blind comparison

Each case requires:

- ORIGIN output
- at least 3 strong reference-system identities
- at least 2 independent multimodal judges
- hidden product identity during judging where operationally possible

Judges score 0-4 on:

1. prompt adherence
2. composition
3. subject integrity
4. style execution
5. text handling
6. artifacting
7. usefulness

They also provide one first-choice preference:
- ORIGIN
- reference
- tie

## Acceptance

The exact round passes only if:

- all 24 cases are present
- all 8 families contain exactly 3 cases
- every image passes deterministic pre-qualification
- every case has >=3 reference systems
- every case has >=2 independent valid judges
- overall win rate >=50%
- overall loss rate <=30%
- overall non-loss rate >=60%
- each image family non-loss rate >=60%
- no rubric axis has a negative mean delta from neutral

All failures remain in the denominator.

## Evidence integrity

The scorer does not require prompt plaintext or image bytes in the public repository.

Evidence includes:

- exact candidate SHA
- exact evaluator SHA
- round ID
- created timestamp
- prompt SHA-256
- ORIGIN image SHA-256
- reference-system IDs
- technical pass/fail facts
- judge IDs, preference, and rubric scores

The scorer emits a SHA-256 digest of the entire evidence packet.

## Executable scorer

```sh
npm run eval:image-blind-quality -- <evidence.json>
```

Schema:

```
origin.image-blind-benchmark.v1
```

## Relationship to world-class quality gate

A passing image blind benchmark is the image-specific evidence source for the higher-level:

```sh
npm run eval:world-class-quality -- <evidence.json>
```

The higher-level gate still requires separate evidence for answers, Coding, general Agent behavior, and artifacts.

## Safety and cost

Benchmark performance cannot override:

- free-only operation
- no paid fallback
- no credit-card dependency
- server-only secrets
- fail-closed provider verification
- user approval boundaries

If the free image path is unavailable, the correct result is blocked/unavailable rather than silently switching to a paid model.
