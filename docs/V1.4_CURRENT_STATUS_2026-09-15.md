## Production alias convergence fix

After PR #266, Production smoke #26 initially passed the exact release health check and then immediately received `CODING_SMOKE_RELEASE_MISMATCH` on the smoke-start POST. Re-running the same main SHA succeeded and launched durable worker #27, proving the Coding implementation itself was healthy and identifying a short Production alias convergence race.

PR #267 was created and merged to main to absorb only this bounded race:

- exact `/api/health` SHA gate is still required
- retry occurs only for HTTP 409 with exact code `CODING_SMOKE_RELEASE_MISMATCH`
- maximum six attempts
- five seconds between attempts
- GitHub OIDC token refreshed per retry
- every other start error remains fail-closed
- provider errors, authentication failures, schema failures, operator readiness failures, and other release failures are not converted into retries or success

PR #267 exact-head CI completed successfully before merge.
