# ORIGIN Brand Icon Rollout — Ribbon O, 2026 design (2026-11-15)

Owner direction: replace the 案H ribbon-O artwork with the new owner-selected
design (candidate A, chosen 2026-11-15): a navy ribbon forming an O with a
small bow knot on top, on a cream rounded-square tile. The font and wording
refresh from the same instruction is handled separately.

## What changed

- Every brand surface keeps its existing path, dimensions, and cache version
  (`?v=ribbon-20261108`); only the artwork changed. The service-worker cache
  is keyed by release SHA, so the new artwork ships with the next release
  without a version-string change. No test expectations changed.
- The approved master artwork (1600×1600) was downscaled into the canonical
  sources in `scripts/brand/` (filter-0 RGB PNGs, as before):
  - `origin-ribbon-o-source.png` (768×768): master.
  - `origin-ribbon-o-small-source.png` (512×512): same framing as the master,
    matching the previous master/small relationship (identical relative
    bounding box, separate render).
  - `origin-ribbon-o-mono-source.png` (256×256): derived from the new artwork
    by segmenting the navy ribbon (blue-dominant dark pixels), area-averaging
    the mask to 256×256 and thresholding at 50%, giving the same flat white
    silhouette on black as the retired mono variant. It remains the source of
    the dark-scheme favicon.
- `public/brand/origin-ribbon-o{,-light,-small,-mono}.webp` were regenerated
  at their previous sizes (512/512/128/256). The new artwork is itself "navy
  ribbon O on cream", which is exactly the light variant's definition, so the
  master and light variants now carry the same rendering.
- Platform PNGs were regenerated by `scripts/generate-origin-brand-icons.mjs`
  from the sources (favicon 64×64, favicon-dark 64×64, apple-touch-icon
  180×180, pwa-192, pwa-512, pwa-maskable-512). Note: the maskable background
  is sampled from the master artwork's corner pixel, which is now white (the
  artwork's outer color) instead of midnight blue.

## Display notes

- Startup splash (`SplashScreen`): the mark sits in a 112px box with
  `border-radius: 24%`, which clips the artwork's white outer corners (the
  cream tile's own corner radius is smaller than 24%), so the splash shows a
  clean cream tile. The navy drop-shadow is unchanged; no CSS change needed.
- In-app header/hero marks remain the cat (Orin) per the 2026-11-09 owner
  direction. The ribbon logo surfaces are the splash, the favicons, and the
  PWA icons. There is no OGP image surface (no `og:image` tags exist).
