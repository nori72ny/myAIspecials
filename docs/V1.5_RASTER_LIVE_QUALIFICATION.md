# Raster Live Qualification V1.5

This qualification is the evidence bridge between ORIGIN's verified raster implementation and a real Cloudflare Workers AI Free production runtime.

## Safety boundary

The qualification never runs implicitly. It requires:

- `ORIGIN_RASTER_LIVE_QUALIFICATION=true`
- server-only `CLOUDFLARE_ACCOUNT_ID`
- server-only `CLOUDFLARE_API_TOKEN`

Do not paste credential values into issues, chat transcripts, logs, or generated evidence.

Before every inference the existing Cloudflare provider re-checks the Workers usage model, active subscriptions, and exact FLUX model schema. Paid-capable or unverifiable paths fail closed.

## What the run proves

One qualification run performs:

1. Workers Free / Billing / model-readiness proof.
2. A 384x384 FLUX text-to-image generation.
3. Structural critic on the generated bytes.
4. Free-only Moondream semantic critic on the generated image.
5. The already-qualified generated image is kept only in memory and reused as the bounded edit reference.
6. FLUX reference edit with preservation/change instructions.
7. Structural critic on the edited bytes.
8. Free-only Moondream semantic critic on the edited image.
9. Evidence serialization without credentials or raw image bytes.

The evidence contains SHA-256 digests, dimensions, provider/model IDs, critic results, phase latency, network-request accounting reported by the provider, and the permanent zero-cost invariants.

## Run

```bash
ORIGIN_RASTER_LIVE_QUALIFICATION=true npm run qualify:raster-live
```

Default evidence path:

`test-results/raster-live-qualification-v15.json`

A custom path may be supplied with `ORIGIN_RASTER_LIVE_EVIDENCE_PATH`.

## Exit codes

- `0`: qualification passed
- `1`: live generation/editing or critic qualification failed
- `2`: intentionally blocked because explicit opt-in, credentials, or verified Free readiness is unavailable

A passing run is operational evidence only. It is not sufficient by itself to claim superiority over leading image systems. The sealed 24-case blind comparison remains required for comparative quality claims.
